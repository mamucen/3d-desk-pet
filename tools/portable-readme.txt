=====================================================
  3D 桌宠 · 便携版（免安装）
=====================================================

【怎么用】
  双击  3D桌宠.exe  即可。
  第一次运行会有 1~2 秒启动，随后桌面上出现小机器人。


【开机自启（和 WorkBuddy 一样，随时可关）】
  右键小机器人（或右键托盘图标）→ 勾选「开机自启（随 Windows 启动）」
  再点一次就是取消。

  开了之后，在 Windows 的「任务管理器 → 启动应用」里能看到一项叫
  3DDeskPet，也可以在那里直接禁用，效果等同于在菜单里取消。

  提示：便携版换文件夹位置后，下次启动会自动把注册表里的路径改成新位置，
  不用重新勾选。


【这个文件夹可以整个拷走】
  这是绿色版，不写系统目录、不装服务。
  整个「3D桌宠」文件夹复制到 U 盘或别的电脑，双击 exe 就能跑。
  换电脑时配置不会跟过去（配置存在每台机器的
  用户目录 AppData\Roaming\desk-pet 里）。


【鼠标能干什么】
  左键拖动   : 挪位置
  右键       : 菜单（皮肤 / 陪看 / 开机自启 / 一键清空缓存 / 看看谁在吃 CPU）
  双击       : 打开管家页面


【快捷键】
  Ctrl+Alt+F      跟随开关
  Ctrl+Alt+Space  随手记一条
  Ctrl+Alt+V      收下剪贴板
  Ctrl+Alt+H      隐身 / 现身
  Ctrl+Alt+B      陪看开关
  Ctrl+Alt+L      打开最新陪看报告
  Ctrl+Alt+R      重启小机器人


【十个皮肤（盲盒）】
  像素喵(R) / 星际喵(SR) / 暴富喵(UR) / 镜头喵(R) / 和平精英喵(R)
  武士喵(SSR) / 火锅喵(UR) / 深海喵(SR) / 夜光喵(SSR)
  右键 → 皮肤 里切换，选择会被记住。


【猿编程联动（可选）】
  在猿编程 IDE 里运行安装目录 resources\app\ 里的示例文件，
  孩子写的代码就能让小机器人说话、换皮肤：
  - 猿编程-联动示例.py           （Python 课程用，纯标准库）
  - 猿编程-联动示例.cpp          （C++ 课程用，调系统自带 curl）
  - 猿编程-联动示例-winsock版.cpp（C++ 进阶，手写 HTTP，需链接 ws2_32）
  接口只开放说话/换肤/现身隐身/跟随，仅本机可访问。

【游荡模式（可选，默认关）】
  右键 → 勾选「游荡模式（在桌面上到处走走）」
  它会自己在桌面上溜达：贴着屏幕边巡游，走一段歇一会儿。

  溜达时会「注意」屏幕上的窗口：
    · 看到微信 / 音乐 / 浏览器 / 编辑器 → 凑近抬头说句话
    · 看到防火墙 / 注册表 / 任务管理器 / 终端 → 一声不响挪到另一头

  安全说明：它只会读取窗口标题来判断"这是什么窗口"，
  不会点击、不会输入、不会调用任何能改变其他软件的接口。
  所以它没有任何能力去关你的防火墙或改你的设置。


【B 站陪看】
  右键打开陪看后，正常看视频即可，看完会自动生成报告。
  B 站接口无需账号、无需密钥，开箱即用。
  报告位置：右键 → 陪看 → 打开报告文件夹


【常见问题】
  Q: 双击没反应？
  A: 检查任务栏右下角托盘，可能已经在运行（同一时间只允许一个实例）。

  Q: 电脑变卡、小机器人变红？
  A: 右键 → 一键清空缓存；或 右键 → 看看谁在吃 CPU / 内存。

  Q: 开机没自动启动？
  A: 先确认菜单里「开机自启」是勾上的；再去 任务管理器 → 启动应用，
     看 3DDeskPet 是不是被系统设成了「已禁用」。

  Q: 想彻底删掉？
  A: 先取消开机自启，再删本文件夹，最后删掉
     AppData\Roaming\desk-pet 即可清干净。
