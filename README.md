# 3D Desk Pet · 3D 桌面小机器人 🤖

一只常驻桌面右下角的 3D 小机器人，配一套「个人信息管家」网页应用。
它会帮你记事、报 CPU/内存，看 B 站视频时自动记笔记、出分析报告，还有 10 款可换的盲盒皮肤。

> 纯本地运行：笔记数据存在你自己的云数据库，B 站接口全部匿名调用，不需要任何账号/密钥。

## 功能一览

**桌面机器人（Electron）**
- 3D 小人常驻桌面：置顶、点击穿透、拖拽、跟随鼠标、全屏自动隐身、开机自启
- 实时负载小机箱：CPU / 内存 / 核心占用滚动显示，另有浏览器大屏面板
- 10 款皮肤：经典机器人 + 像素喵 / 星际喵 / 暴富喵 / 镜头喵 / 和平精英喵 / 武士喵 / 火锅喵 / 深海喵 / 夜光喵，
  换肤后主题色小机箱跟着换，名字 + 稀有度徽章（R / SR / UR / SSR）
- 快捷输入条（随手记）、剪贴板快收、语音播报、原生右键菜单 + 托盘菜单
- 电脑变卡/变红时：右键「一键清空缓存」清掉过期录像与 7 天前临时文件（不动笔记/报告/个人文件），
  「看看谁在吃 CPU / 内存」直接列出最忙的几个进程并一键打开任务管理器
- 与「信息管家」网页联动：消息互通、待办提醒

**猿编程联动（本地接口）**
- 猿编程官方没有对外 API，但它的 IDE 里跑的是真 Python——孩子在猿编程里写的代码，
  可以通过桌宠的本地接口（127.0.0.1:17321）直接指挥小机器人
- `POST /pet/say` 说话（气泡+语音）、`POST /pet/skin` 换皮肤、`POST /pet/act` 现身/隐身/跟随、
  `GET /pet/ping` 查在线状态和 CPU/内存（端口占用时会自动换 17322~17324）
- 示例代码可整段粘贴进猿编程 IDE 直接运行：`猿编程-联动示例.py`（Python，纯标准库）、
  `猿编程-联动示例.cpp`（C++，调用 Windows 10+ 自带的 curl，零依赖零配置）、
  `猿编程-联动示例-winsock版.cpp`（C++ 进阶，纯 WinSock 手写 HTTP，需链接 ws2_32）
- **安全边界**：接口只收白名单动作（说话/换肤/现身隐身/跟随），全是可逆的展示类操作，
  绑定 127.0.0.1 仅本机可访问

**游荡模式（可选，默认关闭）**
- 打开后小机器人会在桌面上自己溜达：贴边巡游、随机停顿、走累了歇一会儿
- 会「注意」屏幕上的窗口：看到微信、音乐播放器、浏览器、代码编辑器这类窗口，
  会凑近抬头说句话；看到 **防火墙、注册表、任务管理器、终端** 这类敏感窗口，
  会悄无声息地挪到另一头去
- **安全边界**：实现上只调用 `desktopCapturer` 读取窗口标题（纯读取，无副作用），
  不模拟点击、不发送按键、不调用任何能改变其他程序状态的接口。
  也就是说它**从架构上就没有操作其他软件的能力**，不可能关掉你的防火墙

**陪看模式（B 站）**
- 检测到你全屏看 B 站视频时自动记录（按窗口标题反查视频）
- 通过 B 站公开 web 接口拿标题 / UP 主 / 时长 / 简介 / 弹幕 /（有登录态时）字幕，
  全部匿名调用：自动领取设备 Cookie，被 412 风控时自动换号重试，开箱即用
- AI 生成观点笔记，并输出一份 PPT 报告（含弹幕高潮时段分析）
- 报告一键打开（Ctrl+Alt+L）、一键清理（走回收站，不硬删）

**个人信息管家（网页）**
- 笔记 / 资料 / 待办：AI 自动分类、摘要、要点、标签、优先级
- 手机号验证码 + 微信扫码登录，数据存在自己的云数据库

## 环境要求

- Node.js ≥ 18（建议 20+）与 npm
- Windows（在 Windows 10/11 + Electron 31 上开发测试；其它平台未验证）
- 运行自动化测试需要 Chrome/Edge（测试脚本用 puppeteer-core 驱动本机 Edge）

## 安装与运行

```bash
git clone https://github.com/mamucen/3d-desk-pet.git
cd 3d-desk-pet/pet-app
npm install
npm start
```

或者安装完依赖后直接双击项目根目录的 `启动小机器人.bat`。

> `npm install` 会下载 Electron（约 100MB），首次启动会慢一点。
> 想让它开机常驻：托盘菜单 →「开机自启」。

## 接入你自己的「信息管家」

项目默认不带线上地址（涉及个人部署，已用占位符）。你有两种用法：

1. **只用桌宠不接管家**：不配置也能跑，笔记会攒在本地待同步队列，但联动功能不可用。
2. **部署自己的管家**：把 `index.html + styles.css + js/ + vendor/` 发布到任意静态托管，
   （或用 WorkBuddy 云服务一键发布），然后把地址（必须带平台要求的分享码）填到两处：
   - `pet-app/main.js` 里的 `DEFAULT_APP_URL`
   - `js/config.js` 里的 `endpoint` / `publishedUrl`

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Alt+Space` | 随手记一条 |
| `Ctrl+Alt+V` | 收下剪贴板 |
| `Ctrl+Alt+F` | 跟随鼠标开关 |
| `Ctrl+Alt+H` | 隐身 / 现身 |
| `Ctrl+Alt+B` | 陪看模式开关 |
| `Ctrl+Alt+L` | 打开最新陪看报告（PPT） |
| `Ctrl+Alt+R` | 重启小机器人 |

右键小机器人 / 托盘图标还有完整菜单：皮肤、清理报告（显示份数与体积）、置顶、语音播报等。

## 运行测试

测试全程 mock 网络与 Electron API，不依赖外网（`test-live-login.js` 除外，它验证线上登录流程，需先配好自己的地址）：

```bash
# 根目录或 pet-app 下安装 puppeteer-core 后：
for f in tools/test-*.js; do node "$f"; done
node tools/smoke-main.js     # 主进程冒烟
```

覆盖：标题反查 BV 号 / wbi 签名与 412 重试 / 弹幕解析 / PPT 报告生成 /
菜单与托盘 / 跟随 / 全屏隐身 / 系统负载 / 皮肤切换与持久化 / 联动桥接。

## 隐私与安全

- 笔记只存在你自己的云数据库；聊天记录 / 设置文件都在本机 userData 目录。
- B 站数据通过官方公开 web 接口匿名获取，不涉及你的 B 站账号（字幕功能如需登录态由浏览器自带）。
- 陪看报告默认写到本地磁盘，「清理报告」走系统回收站，可随时恢复。
